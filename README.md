# LLM Robotic Exploration Experiment

## Overview
Give an LLM access to tools to navigate the environment and explore.


## Sensors
IMU
Encoders
Camera

## Outputs
Motors

## Tools

move_forward (distance in mm)
move_backward (distance in mm)
rotate_counterclockwise (rotation in degrees)
rotate_clockwise (rotation in degrees)
take_picture (None)
